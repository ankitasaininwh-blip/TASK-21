# OmniFood - Responsive Food Delivery Landing Page

## Project Overview

OmniFood is a responsive food delivery landing page created using
HTML and CSS.

The project is inspired by the given OmniFood landing page design
and contains multiple responsive sections.

## Sections

The website contains:

1. Header and Hero Section
2. How It Works Section
3. Our Cities Section
4. Customer Testimonials Section
5. Pricing Plans Section
6. Footer Section

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Make sure the `assets` folder is present.
4. Open `index.html` in any web browser.

No backend or server is required.

## Responsive Breakpoints

### Desktop

Minimum width: 1200px

The complete layout is displayed using CSS Grid and Flexbox.

### Tablet

Maximum width: 834px

- City grid changes to 2 columns.
- Pricing cards stack.
- Testimonials stack vertically.

### Mobile

Maximum width: 390px

- Single-column layout.
- Navigation changes to a hamburger menu.
- Images resize automatically.
- Buttons and text remain readable.
- No horizontal scrolling.

## Responsive Features

The website uses:

- CSS Grid
- CSS Flexbox
- Media Queries
- Responsive images
- Mobile navigation
- Flexible containers
